Not every app list needs 1,000 entries. [awesome-macOS](https://github.com/iCHAIT/awesome-macOS) by iCHAIT is smaller and more selective, and that is what makes it easy to use.

The numbers, as of today:

- **19,000+ stars** and over 1,500 forks.
- **About 280 apps and tools**, in 19 app categories.
- **About half are open source.** The rest are paid or closed-source favorites like Alfred and 1Password.
- It has been around since 2015, one of the oldest Mac lists on GitHub.

## How to read the list

Each app gets one line with a short description. Like awesome-mac, it uses two small badges:

- **Open source:** the code is public, and the badge links to it.
- **Freeware:** free to use.

No badge usually means a paid or closed-source app.

It also has more than apps. Below the app categories you will find command-line tools, step-by-step guides for setting up a new Mac, a security section, and links to Mac communities on Reddit and IRC.

## Categories worth browsing

- **Utilities:** the biggest section, full of small tools that fix everyday annoyances.
- **Productivity:** launchers, automation, and focus tools.
- **Window Management:** snapping and tiling windows.
- **Developers:** Git, database, and Xcode tools.
- **Setup:** guides and scripts for setting up a new Mac, great if you just got one.

## The 25 most-starred apps

The list does not rank its apps, so I used the one public signal it has: **GitHub stars**. I looked up the star count for every open-source app on the list and kept the top 25. I only left out things that are not Mac apps: code libraries, command-line tools, server-only software, and other lists.

Each app shows its category in the list (linked to that section) and its GitHub stars. They are all free unless marked otherwise. Star counts are as of October 2026.

### 1. IINA

**[Video](https://github.com/iCHAIT/awesome-macOS#video) · ⭐ 47k**

IINA is the video player the Mac should have shipped with. It plays almost any format, handles subtitles well, and looks like a modern Mac app, with picture-in-picture and trackpad gestures. If you used VLC on Windows, try IINA first.

![IINA playing a video](/blog/apps/iina.webp)

*Screenshot: [iina.io](https://iina.io/). Get it at [iina.io](https://iina.io) · [GitHub](https://github.com/iina/iina)*

### 2. mpv

**[Video](https://github.com/iCHAIT/awesome-macOS#video) · ⭐ 37k**

mpv is a minimal, powerful video player that plays nearly any format with excellent quality. It has almost no buttons and is controlled with the keyboard and a config file. If you want the same engine with a friendly Mac interface, IINA is built on top of mpv.

![mpv playing a movie](/blog/apps/mpv.webp)

*Screenshot: [mpv.io](https://mpv.io/). Get it at [mpv.io](https://mpv.io) · [GitHub](https://github.com/mpv-player/mpv)*

### 3. MonitorControl

**[Utilities](https://github.com/iCHAIT/awesome-macOS#utilities) · ⭐ 34k**

Your Mac's brightness and volume keys only work on Apple displays. MonitorControl makes them work on most external monitors too, with the same on-screen indicator you get on Apple displays. If you use an external monitor, install this.

![MonitorControl's menu with brightness and volume sliders, and its settings window](/blog/apps/monitorcontrol.webp)

*Screenshot: [MonitorControl on GitHub](https://github.com/MonitorControl/MonitorControl). Get it at [monitorcontrol.app](https://monitorcontrol.app) · [GitHub](https://github.com/MonitorControl/MonitorControl)*

### 4. Rectangle

**[Window Management](https://github.com/iCHAIT/awesome-macOS#window-management) · ⭐ 30k**

Rectangle brings Windows-style window snapping to the Mac. Drag a window to the edge of the screen, or use a keyboard shortcut, to snap it to half, a quarter, or full screen. Newer versions of macOS have some tiling built in, but Rectangle is still faster and more flexible.

![Rectangle's settings with keyboard shortcuts for each window position](/blog/apps/rectangle.webp)

*Screenshot: [Rectangle on GitHub](https://github.com/rxhanson/Rectangle). Get it at [rectangleapp.com](https://rectangleapp.com) · [GitHub](https://github.com/rxhanson/Rectangle)*

### 5. yabai

**[Window Management](https://github.com/iCHAIT/awesome-macOS#window-management) · ⭐ 30k**

yabai is a tiling window manager: it automatically arranges your windows so they never overlap, and you move between them with the keyboard. It is powerful but technical, set up with a config file and usually paired with a hotkey tool. Some features need part of macOS's security protection turned off.

![A Mac desktop with windows tiled by yabai](/blog/apps/yabai.webp)

*Screenshot: [yabai on GitHub](https://github.com/asmvik/yabai). Get it on [GitHub](https://github.com/asmvik/yabai)*

### 6. HandBrake

**[Video](https://github.com/iCHAIT/awesome-macOS#video) · ⭐ 25k**

HandBrake converts video from one format to another. Shrink a huge screen recording, make a file play on an old TV, or turn an MKV into an MP4. Its presets mean you rarely need to touch the advanced settings.

![HandBrake's main window with output settings](/blog/apps/handbrake.webp)

*Screenshot: [handbrake.fr](https://handbrake.fr/). Get it at [handbrake.fr](https://handbrake.fr) · [GitHub](https://github.com/HandBrake/HandBrake)*

### 7. Aerial

**[Others](https://github.com/iCHAIT/awesome-macOS#others) · ⭐ 21k**

Aerial brings the Apple TV's beautiful aerial videos to your Mac's screen saver: slow drone shots of cities, coastlines, and even space. You can pick which videos play and add the time or weather on top.

![Aerial's settings with a list of aerial videos](/blog/apps/aerial.webp)

*Screenshot: [via open-source-mac-os-apps](https://github.com/serhii-londar/open-source-mac-os-apps). Get it on [GitHub](https://github.com/JohnCoates/Aerial)*

### 8. Background Music

**[Audio](https://github.com/iCHAIT/awesome-macOS#audio) · ⭐ 19k**

Background Music adds two things the Mac is missing: a volume slider for each app, and auto-pause, which pauses your music when another app starts playing sound and resumes it after. It can also record what your Mac is playing.

![Background Music's menu with per-app volume sliders](/blog/apps/background-music.webp)

*Screenshot: [Background Music on GitHub](https://github.com/kyleneideck/BackgroundMusic). Get it on [GitHub](https://github.com/kyleneideck/BackgroundMusic)*

### 9. iTerm2

**[Terminal](https://github.com/iCHAIT/awesome-macOS#terminal) · ⭐ 18k**

iTerm2 has been the favorite Terminal replacement on the Mac for years. It adds split panes, search, a hotkey window that drops down from the top of the screen, and many small features that make the command line nicer.

![iTerm2 with split panes](/blog/apps/iterm2.webp)

*Screenshot: [iterm2.com](https://iterm2.com/). Get it at [iterm2.com](https://iterm2.com) · [GitHub](https://github.com/gnachman/iTerm2)*

### 10. BitBar (now xbar)

**[Utilities](https://github.com/iCHAIT/awesome-macOS#utilities) · ⭐ 18k**

BitBar, now called xbar, puts the output of any script in your menu bar. Show a stock price, your build status, or the weather, refreshed on a timer, with hundreds of ready-made plugins to start from. Its last release was in 2021, but it still works.

![xbar showing a custom menu in the menu bar](/blog/apps/bitbar.webp)

*Screenshot: [xbar on GitHub](https://github.com/matryer/xbar). Get it at [xbarapp.com](https://xbarapp.com) · [GitHub](https://github.com/matryer/xbar)*

### 11. OpenEmu

**[Games](https://github.com/iCHAIT/awesome-macOS#games) · ⭐ 18k**

OpenEmu plays retro games from consoles like the NES, SNES, Game Boy, Genesis, and PlayStation, all from one library that looks like iTunes for games. Plug in a controller and it just works. You need to supply your own game files.

![OpenEmu's game library with Sonic playing](/blog/apps/openemu.webp)

*Screenshot: [openemu.org](https://openemu.org/). Get it at [openemu.org](https://openemu.org) · [GitHub](https://github.com/OpenEmu/OpenEmu)*

### 12. Amethyst

**[Window Management](https://github.com/iCHAIT/awesome-macOS#window-management) · ⭐ 16k**

Amethyst automatically tiles your windows into neat layouts, like the Linux window manager xmonad. Unlike yabai, it needs no special setup: install it, grant permission, and choose a layout from the keyboard.

![Amethyst arranging windows into a tiled layout](/blog/apps/amethyst.webp)

*Screenshot: [ianyh.com](https://ianyh.com/amethyst/). Get it at [ianyh.com/amethyst](https://ianyh.com/amethyst/) · [GitHub](https://github.com/ianyh/Amethyst)*

### 13. Hammerspoon

**[Window Management](https://github.com/iCHAIT/awesome-macOS#window-management) · ⭐ 16k**

Hammerspoon lets you automate your Mac with small Lua scripts. Move windows, react when you plug in a monitor or join a Wi-Fi network, or create your own keyboard shortcuts. It has no interface of its own. You write a config file, so it is for people who like to tinker.

*Get it at [hammerspoon.org](https://www.hammerspoon.org) · [GitHub](https://github.com/Hammerspoon/hammerspoon)*

### 14. Dolphin

**[Games](https://github.com/iCHAIT/awesome-macOS#games) · ⭐ 16k**

Dolphin plays Nintendo GameCube and Wii games on your Mac, often at higher resolution than the original consoles. It runs natively on Apple Silicon. As with any emulator, you need your own game files.

*Get it at [dolphin-emu.org](https://dolphin-emu.org) · [GitHub](https://github.com/dolphin-emu/dolphin)*

### 15. Transmission

**[Sharing Files](https://github.com/iCHAIT/awesome-macOS#sharing-files) · ⭐ 15k**

Transmission is a simple, lightweight torrent app that feels at home on the Mac. No ads, no clutter, just your downloads. If qBittorrent feels like too much, start here.

![Transmission's download list on macOS](/blog/apps/transmission.webp)

*Screenshot: [transmissionbt.com](https://transmissionbt.com/). Get it at [transmissionbt.com](https://transmissionbt.com) · [GitHub](https://github.com/transmission/transmission)*

### 16. TextMate

**[Editors](https://github.com/iCHAIT/awesome-macOS#editors) · ⭐ 15k**

TextMate is a classic Mac text editor that inspired many modern ones, including Sublime Text. It is fast and simple, with "bundles" that add support for languages. Updates have been rare in recent years.

![TextMate editing code with a file browser](/blog/apps/textmate.webp)

*Screenshot: [TextMate on GitHub](https://github.com/textmate/textmate). Get it at [macromates.com](https://macromates.com) · [GitHub](https://github.com/textmate/textmate)*

### 17. NoteGen

**[Productivity](https://github.com/iCHAIT/awesome-macOS#productivity) · ⭐ 13k**

NoteGen is a Markdown notes app built around "capture first, organize later." Save quick thoughts, screenshots, and links as they come, then use AI to turn a pile of fragments into a clean note. Your notes stay as local Markdown files.

![NoteGen on desktop and mobile](/blog/apps/notegen.webp)

*Screenshot: [NoteGen on GitHub](https://github.com/codexu/note-gen). Get it at [notegen.top](https://notegen.top) · [GitHub](https://github.com/codexu/note-gen)*

### 18. GitUp

**[Developers](https://github.com/iCHAIT/awesome-macOS#developers) · ⭐ 12k**

GitUp is a fast, visual Git app for the Mac. It shows your project's history as a live graph that you can edit directly, and it lets you undo almost any Git action. A great way to make Git less scary.

![GitUp's commit graph with a context menu](/blog/apps/gitup.webp)

*Screenshot: [via open-source-mac-os-apps](https://github.com/serhii-londar/open-source-mac-os-apps). Get it at [gitup.co](https://gitup.co) · [GitHub](https://github.com/git-up/GitUp)*

### 19. Boring Notch

**[Utilities](https://github.com/iCHAIT/awesome-macOS#utilities) · ⭐ 11k**

Boring Notch turns the notch on your MacBook into something useful, like the iPhone's Dynamic Island. Hover over it to see music controls, a calendar, and a file shelf. On first launch you need to approve it in Privacy and Security, because the app is not signed by Apple.

![Boring Notch expanded to show music controls and a calendar](/blog/apps/boring-notch.webp)

*Screenshot: [Boring Notch on GitHub](https://github.com/TheBoredTeam/boring.notch). Get it on [GitHub](https://github.com/TheBoredTeam/boring.notch)*

### 20. NetNewsWire

**[News Readers](https://github.com/iCHAIT/awesome-macOS#news-readers) · ⭐ 10k**

NetNewsWire is a free RSS reader for Mac and iPhone. Follow blogs and news sites in one place, with no algorithm deciding what you see. It is fast, private, and looks like it was made by Apple.

![NetNewsWire showing a list of articles and an open story](/blog/apps/netnewswire.webp)

*Screenshot: [netnewswire.com](https://netnewswire.com/). Get it at [netnewswire.com](https://netnewswire.com) · [GitHub](https://github.com/Ranchero-Software/NetNewsWire)*

### 21. ImageOptim

**[Developers](https://github.com/iCHAIT/awesome-macOS#developers) · ⭐ 10k**

ImageOptim makes images smaller without changing how they look. Drag in PNGs or JPEGs and it compresses them and strips hidden data like location info. Great before you upload images to a website.

![ImageOptim showing files and the space saved](/blog/apps/imageoptim.webp)

*Screenshot: [imageoptim.com](https://imageoptim.com/mac). Get it at [imageoptim.com/mac](https://imageoptim.com/mac) · [GitHub](https://github.com/ImageOptim/ImageOptim)*

### 22. MacDown

**[Utilities](https://github.com/iCHAIT/awesome-macOS#utilities) · ⭐ 10k**

MacDown is a simple Markdown editor with a live preview next to your text. It is light and easy, but it has not been updated since 2023, so MarkText is a more modern pick.

![MacDown with Markdown on the left and a live preview on the right](/blog/apps/macdown.webp)

*Screenshot: [MacDown on GitHub](https://github.com/MacDownApp/macdown). Get it at [macdown.uranusjr.com](https://macdown.uranusjr.com) · [GitHub](https://github.com/MacDownApp/macdown)*

### 23. Sequel Pro

**[Developers](https://github.com/iCHAIT/awesome-macOS#developers) · ⭐ 9k**

Sequel Pro was the classic Mac app for managing MySQL databases. It is no longer developed, and its last release was in 2016. Its maintained successor, [Sequel Ace](https://sequel-ace.com), is free and works the same way, so install that instead.

*Get it on [GitHub](https://github.com/sequelpro/sequelpro)*

### 24. WWDC

**[Developers](https://github.com/iCHAIT/awesome-macOS#developers) · ⭐ 9k**

This unofficial WWDC app lets you watch Apple's developer conference sessions on your Mac. You can search transcripts, bookmark moments, and download videos to watch offline. Mainly for Apple developers.

![The WWDC app showing a session video and its details](/blog/apps/wwdc.webp)

*Screenshot: [WWDC on GitHub](https://github.com/insidegui/WWDC). Get it at [wwdc.io](https://wwdc.io) · [GitHub](https://github.com/insidegui/WWDC)*

### 25. Xcodes

**[Developers](https://github.com/iCHAIT/awesome-macOS#developers) · ⭐ 9k**

Xcodes makes it easy to install and switch between versions of Xcode, Apple's developer tool. It downloads much faster than the App Store and lets you keep several versions side by side. Mainly for iPhone and Mac developers.

![Xcodes listing Xcode versions to install](/blog/apps/xcodes.webp)

*Screenshot: [Xcodes on GitHub](https://github.com/XcodesOrg/XcodesApp). Get it at [xcodes.app](https://xcodes.app) · [GitHub](https://github.com/XcodesOrg/XcodesApp)*

## Closed-source favorites in this list

Here are the top ten closed-source apps installed most often in the past year, according to Homebrew's public install numbers.

- **[Sublime Text](https://www.sublimetext.com)** · Paid · 62k Homebrew installs: a fast, polished text and code editor. You can try it for free before buying a license.
- **[1Password](https://1password.com)** · Paid · 59k Homebrew installs: a password manager that fills in logins, cards, and addresses for you, with a subscription.
- **[AppCleaner](https://freemacsoft.net/appcleaner/)** · Free · 49k Homebrew installs: drag an app onto it to delete the app along with its leftover files. More in my post on [uninstalling Mac apps](/blog/app-cleaner-uninstall-mac-apps).
- **[Keka](https://www.keka.io)** · Free · 43k Homebrew installs: creates and opens zip, 7z, rar, and many other archive formats. It is free from the website and paid on the App Store, which supports the developer.
- **[Mounty](https://mounty.app)** · Free · 30k Homebrew installs: lets you write to NTFS drives formatted on Windows, which macOS can normally only read.
- **[TablePlus](https://tableplus.com)** · Paid · 29k Homebrew installs: a fast, native database app for PostgreSQL, MySQL, SQLite, and more. The free version has limits.
- **[Alfred](https://www.alfredapp.com)** · Free + paid Powerpack · 24k Homebrew installs: a launcher and Spotlight replacement. The paid Powerpack adds workflows, clipboard history, and snippets.
- **[The Unarchiver](https://theunarchiver.com)** · Free · 23k Homebrew installs: opens almost any archive file, including rar and 7z.
- **[Sourcetree](https://www.sourcetreeapp.com)** · Free · 16k Homebrew installs: a visual Git app from Atlassian.
- **[OnyX](https://www.titanium-software.fr/en/onyx.html)** · Free · 14k Homebrew installs: runs maintenance tasks, clears caches, and unlocks hidden settings.

## Other GitHub lists worth checking

These lists are worth a bookmark too:

- [awesome-mac](https://github.com/jaywcjlove/awesome-mac) (⭐ 115k): the biggest curated list of Mac apps, free and paid, with over 1,300 entries. I picked [the 25 most-starred apps from it](/blog/awesome-mac-best-apps-jaywcjlove).
- [open-source-mac-os-apps](https://github.com/serhii-londar/open-source-mac-os-apps) (⭐ 51k): only open-source Mac apps, with screenshots and the programming language for each one. I picked [the 25 most-starred apps from it](/blog/open-source-mac-apps-serhii-londar).
- [herrbischoff/awesome-macos-command-line](https://github.com/herrbischoff/awesome-macos-command-line) (⭐ 31k): Terminal tricks to change hidden settings and do more from the command line. It is archived now, but still a great reference.
- [mathiasbynens/dotfiles](https://github.com/mathiasbynens/dotfiles) (⭐ 31k): the famous `.macos` script that sets up sensible defaults, mostly for developers.
- [macOS Security and Privacy Guide](https://github.com/drduh/macOS-Security-and-Privacy-Guide) (⭐ 23k): a detailed guide to locking down your Mac.
- [awesome-macos-screensavers](https://github.com/agarrharr/awesome-macos-screensavers) (⭐ 4k): just for fun, a list of screensavers.
- [awesome-windows](https://github.com/0PandaDEV/awesome-windows) (⭐ 3k): the same idea for Windows. Handy for finding the Mac version of an app you used to rely on.
- [awesome-swift-macos-apps](https://github.com/jaywcjlove/awesome-swift-macos-apps) (⭐ 2k): open-source Mac apps written in Swift, from the same maintainer as awesome-mac.
- [awesome-native-macosx-apps](https://github.com/open-saas-directory/awesome-native-macosx-apps) (⭐ 2k): native Mac apps only, nothing built on Electron.
