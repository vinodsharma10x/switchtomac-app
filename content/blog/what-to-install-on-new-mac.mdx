I posted a photo of my new Mac and asked one question: what should I install first?

The replies were better than any list I could have written alone. People shared their daily drivers, the small utilities they cannot work without, and a few I had never heard of. It went around on both X and LinkedIn.

So here is the community list, sorted by how often each app came up, with credit to everyone who chimed in. I have already added AltTab and Raycast myself. The rest are on my list.

## Suggested most

These came up again and again.

- [Homebrew](https://brew.sh/): the package manager for installing command-line tools and apps from the terminal. Suggested five times, by [@prashanttgs](https://x.com/prashanttgs), [@ECL1PTO](https://x.com/ECL1PTO), [@harshgvnd](https://x.com/harshgvnd), [@Deepaksankhyan3](https://x.com/Deepaksankhyan3), and [@Taniyatweets_](https://x.com/Taniyatweets_).
- [Brave](https://brave.com/): a privacy browser with ad and tracker blocking built in. Suggested by [@harshgvnd](https://x.com/harshgvnd), [@vibeonX69](https://x.com/vibeonX69), and [@priya_Thakur786](https://x.com/priya_Thakur786).
- [Claude](https://claude.ai/): Anthropic's AI assistant, which a lot of people, me included, now lean on for coding. Suggested by [@NethikaRE](https://x.com/NethikaRE), Siddharth Verma, and Justin French.
- [Raycast](https://www.raycast.com/): a launcher and Spotlight replacement with extensions and AI built in. Suggested by [@prashanttgs](https://x.com/prashanttgs) and Siddharth Verma.

## Also suggested

Plenty of strong single mentions too.

- [AltTab](https://alt-tab.app/): brings the Windows-style Alt+Tab window switcher to the Mac. Suggested by [@prashanttgs](https://x.com/prashanttgs).
- [Bun](https://bun.sh/): a fast all-in-one JavaScript runtime and package manager. Suggested by [@Deepaksankhyan3](https://x.com/Deepaksankhyan3).
- [Cloudflare Warp](https://1.1.1.1/): a free, fast VPN client from Cloudflare. Suggested by [@harshgvnd](https://x.com/harshgvnd).
- [Codex](https://openai.com/codex): OpenAI's coding agent. Suggested by [@NethikaRE](https://x.com/NethikaRE).
- [CopyClip](https://fiplab.com/apps/copyclip-for-mac): a menu-bar clipboard history manager. Suggested by [@harshgvnd](https://x.com/harshgvnd).
- [Cursor](https://cursor.com/): an AI code editor built on VS Code. Suggested by Siddharth Verma.
- [GitHub Desktop](https://desktop.github.com/): a simple GUI for Git and GitHub. Suggested by [@harshgvnd](https://x.com/harshgvnd).
- [Google Chrome](https://www.google.com/chrome/): the browser, with sync and extensions. Suggested by [@krishna119229](https://x.com/krishna119229).
- [Karabiner Elements](https://karabiner-elements.pqrs.org/): a powerful keyboard remapper, handy when you are coming from a Windows keyboard. Suggested by [@prashanttgs](https://x.com/prashanttgs).
- [Maccy](https://maccy.app/): a lightweight, open-source clipboard manager. Suggested by [@_diksha_irl_](https://x.com/_diksha_irl_).
- [Node.js](https://nodejs.org/): the JavaScript runtime behind most dev tools. Suggested by [@Deepaksankhyan3](https://x.com/Deepaksankhyan3).
- [Numi](https://numi.app/): a natural-language calculator for quick math, currency, and units. Suggested by [@harshgvnd](https://x.com/harshgvnd).
- [Oh My Zsh](https://ohmyz.sh/): a framework for configuring the Zsh shell with plugins and themes. Suggested by Siddharth Verma.
- [Telegram](https://telegram.org/): fast, secure messaging. Suggested by [@harshgvnd](https://x.com/harshgvnd).
- [Todoist](https://todoist.com/): task and project management. Suggested by Siddharth Verma.
- [VLC](https://www.videolan.org/vlc/): plays virtually any audio or video file you throw at it. Suggested by [@harshgvnd](https://x.com/harshgvnd).
- [VS Code](https://code.visualstudio.com/): Microsoft's free, extensible code editor. Suggested by [@harshgvnd](https://x.com/harshgvnd).
- [Wispr Flow](https://wisprflow.ai/): AI dictation that types what you say in any app. Suggested by Siddharth Verma.

A few more came up too: a VPN like Windscribe ([@ElectroNow_AT](https://x.com/ElectroNow_AT)), an antivirus ([@eth_ansh](https://x.com/eth_ansh)), running web tools as Chrome apps ([@SaraJai2417](https://x.com/SaraJai2417)), and the Littlebird and Hermes AI agents (Rohit Sharma, [@docjais](https://x.com/docjais)).
