Every app in this list has one thing in common: its code is public. You can see how it works, and you never have to wonder what it does with your data.

[open-source-mac-os-apps](https://github.com/serhii-londar/open-source-mac-os-apps) is a GitHub list of open-source Mac apps, started by Serhii Londar in 2017.

The numbers, as of today:

- **51,000+ stars** and almost 3,000 forks.
- **862 apps** across 39 categories.
- **Every one of them is open source**, and almost all are free.

## How to read the list

Each entry is more detailed than most lists. You get the app's name and a short description, plus:

- **Languages:** small icons showing what the app is written in, like Swift, C++, or JavaScript. Native Mac apps are usually Swift or Objective-C.
- **Website:** a link to the app's homepage, when it has one.
- **Screenshots:** a collapsed section you can click to open. This is the best part, because you can see an app before you download anything.

Because everything is open source, the name of each app links straight to its source code on GitHub.

## Categories worth browsing

The sections are listed alphabetically with the number of apps in each. The biggest ones are where most of the good stuff is:

- **Utilities** (126 apps): the catch-all for small, useful tools.
- **Productivity** (81): notes, to-do lists, time tracking, and launchers.
- **Menubar** (59): little apps that live in the top bar of your screen.
- **Audio** (40): recorders, players, and sound controls.
- **Window Management** (17): snapping and tiling windows.
- **Terminal, IDE, and Development:** if you write code.

## The 25 most-starred apps

The list does not rank its apps, so I used the one public signal it has: **GitHub stars**. I looked up the star count for every open-source app on the list and kept the top 25. I only left out things that are not Mac apps: code libraries, command-line tools, server-only software, and other lists.

Each app shows its category in the list (linked to that section) and its GitHub stars. They are all free unless marked otherwise. Star counts are as of October 2026.

### 1. Visual Studio Code

**[IDE](https://github.com/serhii-londar/open-source-mac-os-apps#-ide-14) · ⭐ 193k**

VS Code is Microsoft's free code editor and the most popular one in the world. It supports almost every language through extensions, has Git and a terminal built in, and works with AI assistants like GitHub Copilot. If you write any code at all, you will probably end up here.

![Visual Studio Code with code, a file tree, and the terminal](/blog/apps/vscode.webp)

*Screenshot: [VS Code on GitHub](https://github.com/microsoft/vscode). Get it at [code.visualstudio.com](https://code.visualstudio.com) · [GitHub](https://github.com/microsoft/vscode)*

### 2. Stirling-PDF

**[Utilities](https://github.com/serhii-londar/open-source-mac-os-apps#%EF%B8%8F-utilities-126) · ⭐ 94k · Free + paid plans**

Stirling-PDF has over 50 PDF tools in one place: merge, split, sign, redact, convert, compress, and OCR. Unlike most free PDF websites, you can run it on your own Mac as a desktop app, so your documents never leave your computer. Paid plans are for companies running it on their own servers.

![Stirling-PDF's dashboard with its list of PDF tools](/blog/apps/stirling-pdf.webp)

*Screenshot: [Stirling-PDF on GitHub](https://github.com/Stirling-Tools/Stirling-PDF). Get it at [stirling.com](https://stirling.com) · [GitHub](https://github.com/Stirling-Tools/Stirling-PDF)*

### 3. Zed

**[Editors](https://github.com/serhii-londar/open-source-mac-os-apps#-editors-8) · ⭐ 91k · Free + paid plans**

Zed is a code editor built for speed, from the people who created Atom. It opens instantly, stays smooth on big projects, and has AI assistance and real-time collaboration built in. The editor is free, and there are paid plans for more AI usage. If VS Code feels heavy, try Zed.

![The Zed editor with its AI agent panel](/blog/apps/zed.webp)

*Screenshot: [zed.dev](https://zed.dev/). Get it at [zed.dev](https://zed.dev) · [GitHub](https://github.com/zed-industries/zed)*

### 4. Bitcoin Core

**[Cryptocurrency](https://github.com/serhii-londar/open-source-mac-os-apps#-cryptocurrency-5) · ⭐ 90k**

Bitcoin Core is the original Bitcoin software. It runs a full Bitcoin node on your Mac, downloading and checking the entire blockchain yourself, and includes a wallet. It needs a lot of disk space, so it is mainly for people who want to verify everything themselves.

![Bitcoin Core's wallet with a list of transactions](/blog/apps/bitcoin-core.webp)

*Screenshot: [bitcoincore.org](https://bitcoincore.org/). Get it at [bitcoincore.org](https://bitcoincore.org) · [GitHub](https://github.com/bitcoin/bitcoin)*

### 5. OBS Studio

**[Streaming](https://github.com/serhii-londar/open-source-mac-os-apps#-streaming-3) · ⭐ 77k**

OBS is the free standard for screen recording and live streaming. You build "scenes" from sources like your screen, a window, your webcam, and your mic, then record or stream to YouTube or Twitch. It takes a few minutes to learn, but nothing free comes close for tutorials, demos, or streaming.

![The OBS Studio window with a scene preview and audio mixer](/blog/apps/obs.webp)

*Screenshot: [obsproject.com](https://obsproject.com/). Get it at [obsproject.com](https://obsproject.com) · [GitHub](https://github.com/obsproject/obs-studio)*

### 6. Tabby

**[Terminal](https://github.com/serhii-londar/open-source-mac-os-apps#-terminal-16) · ⭐ 75k**

Tabby is a modern, highly customizable terminal. It has tabs, split panes, themes, and a built-in SSH and serial client that remembers your connections. It runs on Mac, Windows, and Linux, so your terminal feels the same everywhere.

![The Tabby terminal](/blog/apps/tabby.webp)

*Screenshot: [Tabby on GitHub](https://github.com/Eugeny/tabby). Get it at [tabby.sh](https://tabby.sh) · [GitHub](https://github.com/Eugeny/tabby)*

### 7. Alacritty

**[Terminal](https://github.com/serhii-londar/open-source-mac-os-apps#-terminal-16) · ⭐ 66k**

Alacritty is a terminal built for one thing: speed. It uses your GPU to draw text, has no tabs or extra features, and is configured with a simple text file. People often pair it with tmux or Zellij for tabs and splits.

![The Alacritty terminal showing code](/blog/apps/alacritty.webp)

*Screenshot: [via open-source-mac-os-apps](https://github.com/serhii-londar/open-source-mac-os-apps). Get it at [alacritty.org](https://alacritty.org) · [GitHub](https://github.com/alacritty/alacritty)*

### 8. MarkText

**[Editors](https://github.com/serhii-londar/open-source-mac-os-apps#-editors-8) · ⭐ 62k**

MarkText is a clean Markdown editor where you see the formatted result as you type, instead of a split preview. It supports tables, code blocks, math, and diagrams, and exports to HTML and PDF.

![MarkText editing a Markdown document](/blog/apps/marktext.webp)

*Screenshot: [MarkText on GitHub](https://github.com/marktext/marktext). Get it at [marktext.me](https://www.marktext.me) · [GitHub](https://github.com/marktext/marktext)*

### 9. Joplin

**[Notes](https://github.com/serhii-londar/open-source-mac-os-apps#-notes-19) · ⭐ 57k · Free + paid plans**

Joplin is an open-source notes app, and a good fit if you are leaving OneNote or Evernote. Notes are written in Markdown, organized in notebooks, and can sync through Dropbox, OneDrive, or the paid Joplin Cloud, with end-to-end encryption. There are apps for every platform, including Windows and phones.

![Joplin on a laptop and a phone](/blog/apps/joplin.webp)

*Screenshot: [Joplin on GitHub](https://github.com/laurent22/joplin). Get it at [joplinapp.org](https://joplinapp.org) · [GitHub](https://github.com/laurent22/joplin)*

### 10. Motrix

**[Downloader](https://github.com/serhii-londar/open-source-mac-os-apps#%EF%B8%8F-downloader-10) · ⭐ 56k**

Motrix is a download manager for big files. It speeds up downloads by splitting them into parts, and it handles HTTP, FTP, torrents, and magnet links in one simple window. Its last release was in 2023, but it still works well.

![Motrix's download list](/blog/apps/motrix.webp)

*Screenshot: [Motrix on GitHub](https://github.com/agalwood/Motrix). Get it at [motrix.app](https://motrix.app) · [GitHub](https://github.com/agalwood/Motrix)*

### 11. DBeaver

**[Database](https://github.com/serhii-londar/open-source-mac-os-apps#%EF%B8%8F-database-18) · ⭐ 52k · Free + paid plans**

DBeaver is a free database tool that connects to almost anything: PostgreSQL, MySQL, SQLite, SQL Server, and many more. Browse tables, run SQL, and edit data from one app. The Community edition is free, and paid editions add more features.

![DBeaver with a database table and SQL editor](/blog/apps/dbeaver.webp)

*Screenshot: [dbeaver.io](https://dbeaver.io/). Get it at [dbeaver.io](https://dbeaver.io) · [GitHub](https://github.com/dbeaver/dbeaver)*

### 12. IINA

**[Player](https://github.com/serhii-londar/open-source-mac-os-apps#%EF%B8%8F-player-6) · ⭐ 47k**

IINA is the video player the Mac should have shipped with. It plays almost any format, handles subtitles well, and looks like a modern Mac app, with picture-in-picture and trackpad gestures. If you used VLC on Windows, try IINA first.

![IINA playing a video](/blog/apps/iina.webp)

*Screenshot: [iina.io](https://iina.io/). Get it at [iina.io](https://iina.io) · [GitHub](https://github.com/iina/iina)*

### 13. Hyper

**[Terminal](https://github.com/serhii-londar/open-source-mac-os-apps#-terminal-16) · ⭐ 45k**

Hyper is a terminal built with web technologies, which makes it easy to theme and extend with plugins written in JavaScript. Its last release was in early 2023, so newer options like Ghostty are a better pick today.

![The Hyper terminal window](/blog/apps/hyper.webp)

*Screenshot: [hyper.is](https://hyper.is/). Get it at [hyper.is](https://hyper.is) · [GitHub](https://github.com/vercel/hyper)*

### 14. LosslessCut

**[Audio](https://github.com/serhii-londar/open-source-mac-os-apps#-audio-40) · ⭐ 44k**

LosslessCut trims and splits video and audio without re-encoding. That means it is nearly instant and the quality stays exactly the same. It is perfect for cutting the boring parts out of a long recording before you share it.

![LosslessCut with a video timeline and cut segments](/blog/apps/losslesscut.webp)

*Screenshot: [LosslessCut on GitHub](https://github.com/mifi/lossless-cut). Get it at [losslesscut.app](https://losslesscut.app) · [GitHub](https://github.com/mifi/lossless-cut)*

### 15. Stats

**[Menubar](https://github.com/serhii-londar/open-source-mac-os-apps#-menubar-59) · ⭐ 42k**

Stats is the closest thing to Task Manager in your menu bar. It shows CPU, memory, disk, network, battery, and temperatures at a glance, and clicking each one opens a detailed panel. It is free and very light.

![Stats menu bar panels for CPU, GPU, memory, disk, network, and battery](/blog/apps/stats.webp)

*Screenshot: [mac-stats.com](https://mac-stats.com/). Get it at [mac-stats.com](https://mac-stats.com) · [GitHub](https://github.com/exelban/stats)*

### 16. Vim

**[IDE](https://github.com/serhii-londar/open-source-mac-os-apps#-ide-14) · ⭐ 41k**

Vim is the classic keyboard-driven text editor, and it already comes with every Mac. Type `vim` in Terminal to open it. Once you learn its shortcuts you can edit text very fast, which is why it has been loved for over 30 years.

![Vim editing code with a search results list](/blog/apps/vim.webp)

*Screenshot: [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Vim-search-copen-quickfix.png). Get it at [vim.org](https://www.vim.org) · [GitHub](https://github.com/vim/vim)*

### 17. qBittorrent

**[Sharing Files](https://github.com/serhii-londar/open-source-mac-os-apps#-sharing-files-12) · ⭐ 41k**

qBittorrent is a free, ad-free torrent app. It has a built-in search, lets you pick which files in a torrent to download, and can schedule downloads. It is a clean alternative to apps that come with ads.

![qBittorrent's main window with a download in progress](/blog/apps/qbittorrent.webp)

*Screenshot: [qbittorrent.org](https://www.qbittorrent.org/). Get it at [qbittorrent.org](https://www.qbittorrent.org) · [GitHub](https://github.com/qbittorrent/qBittorrent)*

### 18. Insomnia

**[Development](https://github.com/serhii-londar/open-source-mac-os-apps#%E2%80%8D-development-19) · ⭐ 40k · Free + paid plans**

Insomnia is an API client for testing REST, GraphQL, WebSocket, and gRPC APIs. It is a popular alternative to Postman, with a free tier and paid plans for teams.

![Insomnia sending an API request](/blog/apps/insomnia.webp)

*Screenshot: [Insomnia on GitHub](https://github.com/Kong/insomnia). Get it at [insomnia.rest](https://insomnia.rest) · [GitHub](https://github.com/Kong/insomnia)*

### 19. Aseprite

**[Graphics](https://github.com/serhii-londar/open-source-mac-os-apps#-graphics-17) · ⭐ 40k · Paid**

Aseprite is the go-to app for pixel art and sprite animation, used by many indie game developers. The ready-to-use app is paid. The source code is public, so you can also build it yourself for free if you are comfortable with that.

![Aseprite's animation timeline with layers and frames](/blog/apps/aseprite.webp)

*Screenshot: [aseprite.org](https://www.aseprite.org/). Get it at [aseprite.org](https://www.aseprite.org) · [GitHub](https://github.com/aseprite/aseprite)*

### 20. mpv

**[Audio](https://github.com/serhii-londar/open-source-mac-os-apps#-audio-40) · ⭐ 37k**

mpv is a minimal, powerful video player that plays nearly any format with excellent quality. It has almost no buttons and is controlled with the keyboard and a config file. If you want the same engine with a friendly Mac interface, IINA is built on top of mpv.

![mpv playing a movie](/blog/apps/mpv.webp)

*Screenshot: [mpv.io](https://mpv.io/). Get it at [mpv.io](https://mpv.io) · [GitHub](https://github.com/mpv-player/mpv)*

### 21. kitty

**[Terminal](https://github.com/serhii-londar/open-source-mac-os-apps#-terminal-16) · ⭐ 35k**

kitty is a fast, GPU-powered terminal with tabs, split windows, and the ability to show images right in the terminal. It is very configurable and popular with people who live in the command line.

![kitty with several split panes](/blog/apps/kitty.webp)

*Screenshot: [kitty](https://sw.kovidgoyal.net/kitty/). Get it at [sw.kovidgoyal.net/kitty](https://sw.kovidgoyal.net/kitty/) · [GitHub](https://github.com/kovidgoyal/kitty)*

### 22. balenaEtcher

**[Utilities](https://github.com/serhii-londar/open-source-mac-os-apps#%EF%B8%8F-utilities-126) · ⭐ 34k**

balenaEtcher writes a disk image to a USB drive or SD card in three clicks: pick the image, pick the drive, flash. It checks the result and hides your Mac's internal drive so you cannot erase it by accident. Handy for making a Linux or Raspberry Pi drive.

*Get it at [etcher.balena.io](https://etcher.balena.io) · [GitHub](https://github.com/balena-io/etcher)*

### 23. MonitorControl

**[Audio](https://github.com/serhii-londar/open-source-mac-os-apps#-audio-40) · ⭐ 34k**

Your Mac's brightness and volume keys only work on Apple displays. MonitorControl makes them work on most external monitors too, with the same on-screen indicator you get on Apple displays. If you use an external monitor, install this.

![MonitorControl's menu with brightness and volume sliders, and its settings window](/blog/apps/monitorcontrol.webp)

*Screenshot: [MonitorControl on GitHub](https://github.com/MonitorControl/MonitorControl). Get it at [monitorcontrol.app](https://monitorcontrol.app) · [GitHub](https://github.com/MonitorControl/MonitorControl)*

### 24. FreeCAD

**[Graphics](https://github.com/serhii-londar/open-source-mac-os-apps#-graphics-17) · ⭐ 34k**

FreeCAD is a free 3D CAD app for designing real-world objects, from 3D-printed parts to furniture and buildings. You design with exact measurements and can change any dimension later. It is a free alternative to tools like Fusion 360 or SolidWorks.

![FreeCAD modeling a 3D part](/blog/apps/freecad.webp)

*Screenshot: [FreeCAD on GitHub](https://github.com/FreeCAD/FreeCAD). Get it at [freecad.org](https://www.freecad.org) · [GitHub](https://github.com/FreeCAD/FreeCAD)*

### 25. VSCodium

**[IDE](https://github.com/serhii-londar/open-source-mac-os-apps#-ide-14) · ⭐ 34k**

VSCodium is VS Code without Microsoft's branding and telemetry. It is built from the same open-source code, so it looks and works the same. The main difference is that it uses a different extension store, so a few Microsoft-only extensions are not available.

![VSCodium editing code](/blog/apps/vscodium.webp)

*Screenshot: [vscodium.com](https://vscodium.com/). Get it at [vscodium.com](https://vscodium.com) · [GitHub](https://github.com/VSCodium/vscodium)*

## Other GitHub lists worth checking

These lists are worth a bookmark too:

- [awesome-mac](https://github.com/jaywcjlove/awesome-mac) (⭐ 115k): the biggest curated list of Mac apps, free and paid, with over 1,300 entries. I picked [the 25 most-starred apps from it](/blog/awesome-mac-best-apps-jaywcjlove).
- [iCHAIT/awesome-macOS](https://github.com/iCHAIT/awesome-macOS) (⭐ 19k): a smaller, hand-picked list of free and paid Mac apps, plus setup guides. I picked [the 25 most-starred apps from it](/blog/awesome-macos-best-apps-ichait).
- [herrbischoff/awesome-macos-command-line](https://github.com/herrbischoff/awesome-macos-command-line) (⭐ 31k): Terminal tricks to change hidden settings and do more from the command line. It is archived now, but still a great reference.
- [mathiasbynens/dotfiles](https://github.com/mathiasbynens/dotfiles) (⭐ 31k): the famous `.macos` script that sets up sensible defaults, mostly for developers.
- [macOS Security and Privacy Guide](https://github.com/drduh/macOS-Security-and-Privacy-Guide) (⭐ 23k): a detailed guide to locking down your Mac.
- [awesome-macos-screensavers](https://github.com/agarrharr/awesome-macos-screensavers) (⭐ 4k): just for fun, a list of screensavers.
- [awesome-windows](https://github.com/0PandaDEV/awesome-windows) (⭐ 3k): the same idea for Windows. Handy for finding the Mac version of an app you used to rely on.
- [awesome-swift-macos-apps](https://github.com/jaywcjlove/awesome-swift-macos-apps) (⭐ 2k): open-source Mac apps written in Swift, from the same maintainer as awesome-mac.
- [awesome-native-macosx-apps](https://github.com/open-saas-directory/awesome-native-macosx-apps) (⭐ 2k): native Mac apps only, nothing built on Electron.
