Some Mac apps feel instant. They open in a blink, barely touch your battery, and behave exactly like the apps Apple makes. Others feel like a website in a window. The difference is usually whether the app is native.

I went through five GitHub lists that track native Mac apps and pulled out the 25 most-starred ones.

## What makes an app native?

A native Mac app is built with Apple's own tools: the Swift or Objective-C programming languages and Apple's AppKit or SwiftUI frameworks. Many popular apps, like Slack, Discord, and VS Code, are instead built with Electron, which packs a copy of the Chrome browser inside the app.

Electron makes it easy to ship one app for Mac, Windows, and Linux, but it has a cost. Native apps usually:

- **Start faster** and feel more responsive.
- **Use less memory and battery**, which matters on a MacBook.
- **Behave like a Mac app**, with the right menus, shortcuts, settings, and features like Quick Look and Shortcuts.

If you just moved from Windows, choosing native apps is one of the easiest ways to get the most out of your Mac.

## Where this list comes from

Five GitHub lists, combined:

- [awesome-native-macosx-apps](https://github.com/open-saas-directory/awesome-native-macosx-apps) (⭐ 1.6k): about 220 native apps, each marked free, paid, freemium, or open source.
- [awesome-swift-macos-apps](https://github.com/jaywcjlove/awesome-swift-macos-apps) (⭐ 1.7k): more than 1,200 open-source Mac apps written in Swift, from the maintainer of awesome-mac.
- [jeffreyjackson/mac-apps](https://github.com/jeffreyjackson/mac-apps) (⭐ 1.6k): an older list of open-source Mac apps, started in 2015.
- [awesome-mac](https://github.com/jaywcjlove/awesome-mac) (⭐ 115k): the biggest Mac app list, which marks native apps with a badge.
- [open-source-mac-os-apps](https://github.com/serhii-londar/open-source-mac-os-apps) (⭐ 51k): shows each app's programming language, so I included the apps written in Swift or Objective-C.

Together that is about 1,500 apps. To keep only real native apps, I checked each app's main programming language on GitHub and kept the ones written in Swift or Objective-C. A few apps with a native Mac interface but a different core language, like HandBrake and VLC, count too. Apps that some lists call native but are not, like Electron and Java apps, are left out.


## The 25 most-starred native Mac apps

Then I ranked them by **GitHub stars**, leaving out command-line tools, code libraries, and archived projects. Each app shows its category, its stars, and which of the five lists include it. The more lists an app appears in, the more people agree it is worth installing. All 25 are free and open source. Star counts are as of October 2026.

### 1. IINA

**Video & Media · ⭐ 47k**

*In 3 of 5 lists: [awesome-native-macosx-apps](https://github.com/open-saas-directory/awesome-native-macosx-apps), [awesome-swift-macos-apps](https://github.com/jaywcjlove/awesome-swift-macos-apps), [open-source-mac-os-apps](https://github.com/serhii-londar/open-source-mac-os-apps)*

IINA is the video player the Mac should have shipped with. It plays almost any format, handles subtitles well, and looks like a modern Mac app, with picture-in-picture and trackpad gestures. If you used VLC on Windows, try IINA first.

![IINA playing a video](/blog/apps/iina.webp)

*Screenshot: [iina.io](https://iina.io/). Get it at [iina.io](https://iina.io) · [GitHub](https://github.com/iina/iina)*

### 2. Stats

**System Utilities · ⭐ 42k**

*In 3 of 5 lists: [awesome-native-macosx-apps](https://github.com/open-saas-directory/awesome-native-macosx-apps), [awesome-swift-macos-apps](https://github.com/jaywcjlove/awesome-swift-macos-apps), [open-source-mac-os-apps](https://github.com/serhii-londar/open-source-mac-os-apps)*

Stats is the closest thing to Task Manager in your menu bar. It shows CPU, memory, disk, network, battery, and temperatures at a glance, and clicking each one opens a detailed panel. It is free and very light.

![Stats menu bar panels for CPU, GPU, memory, disk, network, and battery](/blog/apps/stats.webp)

*In 1 of 5 lists: [awesome-swift-macos-apps](https://github.com/jaywcjlove/awesome-swift-macos-apps)*

### 4. MonitorControl

Your Mac's brightness and volume keys only work on Apple displays. MonitorControl makes them work on most external monitors too, with the same on-screen indicator you get on Apple displays. If you use an external monitor, install this.

### 5. ShadowsocksX-NG

### 6. Rectangle

**Window Management · ⭐ 30k**

*In 3 of 5 lists: [awesome-native-macosx-apps](https://github.com/open-saas-directory/awesome-native-macosx-apps), [awesome-swift-macos-apps](https://github.com/jaywcjlove/awesome-swift-macos-apps), [open-source-mac-os-apps](https://github.com/serhii-londar/open-source-mac-os-apps)*

Rectangle brings Windows-style window snapping to the Mac. Drag a window to the edge of the screen, or use a keyboard shortcut, to snap it to half, a quarter, or full screen. Newer versions of macOS have some tiling built in, but Rectangle is still faster and more flexible.

## Closed-source favorites

Here are the top ten closed-source native apps from these lists installed most often in the past year, according to Homebrew's public install numbers.

- **[Raycast](https://www.raycast.com)** · Free + paid plans · 116k Homebrew installs: a launcher that replaces Spotlight, with clipboard history, window management, snippets, and AI. I wrote [a whole post about it](/blog/raycast).
- **[AppCleaner](https://freemacsoft.net/appcleaner/)** · Free · 49k Homebrew installs: drag an app onto it to delete the app along with its leftover files. More in my post on [uninstalling Mac apps](/blog/app-cleaner-uninstall-mac-apps).
- **[TablePlus](https://tableplus.com)** · Paid · 29k Homebrew installs: a fast database app for PostgreSQL, MySQL, SQLite, and more. The free version has limits.
- **[Shottr](https://shottr.cc)** · Free · 26k Homebrew installs: a fast screenshot tool with scrolling capture, text recognition, and annotation.
- **[Alfred](https://www.alfredapp.com)** · Free + paid Powerpack · 24k Homebrew installs: a launcher and Spotlight replacement. The paid Powerpack adds workflows, clipboard history, and snippets.
- **[The Unarchiver](https://theunarchiver.com)** · Free · 23k Homebrew installs: opens almost any archive file, including rar and 7z.
- **[Sourcetree](https://www.sourcetreeapp.com)** · Free · 16k Homebrew installs: a visual Git app from Atlassian.
- **[OnyX](https://www.titanium-software.fr/en/onyx.html)** · Free · 14k Homebrew installs: runs maintenance tasks, clears caches, and unlocks hidden settings.
