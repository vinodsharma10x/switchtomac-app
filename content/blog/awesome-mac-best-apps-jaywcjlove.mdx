When you move to a Mac, the hardest part is not the keyboard. It is figuring out which apps to install.

There is a GitHub project that does most of that work for you. [awesome-mac](https://github.com/jaywcjlove/awesome-mac) is a community-maintained list of Mac apps, sorted by category, and it is one of the most popular lists on GitHub.

The numbers, as of today:

- **115,000+ stars** and over 9,000 forks.
- **More than 1,300 apps** across 24 categories.
- **Over 700 of them are open source.**
- It is still updated almost every day.

It is a great bookmark, but 1,300 apps is a lot. So I went through it and pulled out the ones worth starting with.

## How to read the list

Each app gets one line: a name, a link, and a short description. After that, a few small badges tell you what kind of app it is.

- **Open source:** the code is public on GitHub, and the badge links to it.
- **Freeware:** free to use.
- **App Store:** available from the Mac App Store.

Apps with no badge are usually paid or closed source, and many of the best Mac apps are in that group. The list also includes a blocklist of pirated software sites, which tells you the maintainers care about where your apps come from.

My tip: do not read it top to bottom. Open the table of contents, jump to the category you need right now, and skim.

## Categories worth browsing

The biggest category by far is **Utilities**, with over 400 apps. That is where most of the "how did I live without this" apps live. A few sections are especially useful if you are new to the Mac:

- **Window Management:** snapping and switching windows the way you did on Windows.
- **Clipboard Tools:** clipboard history, like Win+V.
- **Menu Bar Tools:** small apps that live in the top bar of the screen.
- **Cleanup and Uninstall:** removing apps completely.
- **Developer Tools and Terminal Apps:** editors, terminals, and API tools, if you write code.
- **AI Tools and Voice-to-Text:** the newest and fastest-growing sections.
- **Package Managers:** install apps from the terminal with one command.

## The 25 most-starred apps

The list does not rank its apps, so I used the one public signal it has: **GitHub stars**. I looked up the star count for every open-source app on the list and kept the top 25. I only left out things that are not Mac apps: code libraries, command-line tools, server-only software, and other lists.

Each app shows its category in the list (linked to that section) and its GitHub stars. They are all free unless marked otherwise. Star counts are as of October 2026.

### 1. CC Switch

**[Developer Tools](https://github.com/jaywcjlove/awesome-mac#developer-tools) / [Developer Utilities](https://github.com/jaywcjlove/awesome-mac#developer-utilities) · ⭐ 140k**

If you use AI coding tools like Claude Code, Codex, or Gemini CLI, each one keeps its settings in its own config file. CC Switch puts them all in one desktop app. Pick a provider, paste your key, and switch with one click, without hand-editing JSON or YAML files. It also manages MCP servers, skills, and prompts in one place, and shows your token usage.

![CC Switch's main window listing AI API providers](/blog/apps/cc-switch.webp)

*Screenshot: [CC Switch on GitHub](https://github.com/farion1231/cc-switch). Get it at [ccswitch.io](https://ccswitch.io) · [GitHub](https://github.com/farion1231/cc-switch)*

### 2. RustDesk

**[Remote Login Software](https://github.com/jaywcjlove/awesome-mac#remote-login-software) · ⭐ 125k · Free + paid plans**

RustDesk is an open-source alternative to TeamViewer and AnyDesk. Use it to help a family member with their computer, or reach your own PC from your Mac. It works out of the box with free public servers, and if you want full control you can run your own server.

![RustDesk controlling a remote computer](/blog/apps/rustdesk.webp)

*Screenshot: [RustDesk on GitHub](https://github.com/rustdesk/rustdesk). Get it at [rustdesk.com](https://rustdesk.com) · [GitHub](https://github.com/rustdesk/rustdesk)*

### 3. Neovim

**[Reading and Writing Tools](https://github.com/jaywcjlove/awesome-mac#reading-and-writing-tools) / [Text Editors](https://github.com/jaywcjlove/awesome-mac#text-editors) · ⭐ 103k**

Neovim is a modern take on Vim, the keyboard-driven text editor that runs in your terminal. It is fast, scriptable in Lua, and has a huge plugin ecosystem, so many developers turn it into a full code editor. It has a learning curve, but people who learn it rarely go back. Install it with `brew install neovim`.

![Neovim's start screen in a terminal](/blog/apps/neovim.webp)

*Screenshot: [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Neovim_0.5.0_screenshot.png). Get it at [neovim.io](https://neovim.io) · [GitHub](https://github.com/neovim/neovim)*

### 4. LocalSend

**[Communication](https://github.com/jaywcjlove/awesome-mac#communication) / [File Sharing](https://github.com/jaywcjlove/awesome-mac#file-sharing) · ⭐ 93k**

AirDrop is great until you need to send a file to a Windows PC or an Android phone. LocalSend fills that gap. Install it on each device, and they find each other on your Wi-Fi network. Files go straight from one device to the other, no internet, account, or cloud upload needed. It runs on Mac, Windows, Linux, Android, and iPhone, so it is perfect for a home that is not all Apple yet.

![LocalSend receiving files on a laptop](/blog/apps/localsend.webp)

*Screenshot: [localsend.org](https://localsend.org/). Get it at [localsend.org](https://localsend.org) · [GitHub](https://github.com/localsend/localsend)*

### 5. Zed

**[Reading and Writing Tools](https://github.com/jaywcjlove/awesome-mac#reading-and-writing-tools) / [Text Editors](https://github.com/jaywcjlove/awesome-mac#text-editors) · ⭐ 91k · Free + paid plans**

Zed is a code editor built for speed, from the people who created Atom. It opens instantly, stays smooth on big projects, and has AI assistance and real-time collaboration built in. The editor is free, and there are paid plans for more AI usage. If VS Code feels heavy, try Zed.

![The Zed editor with its AI agent panel](/blog/apps/zed.webp)

*Screenshot: [zed.dev](https://zed.dev/). Get it at [zed.dev](https://zed.dev) · [GitHub](https://github.com/zed-industries/zed)*

### 6. Orca

**[Developer Tools](https://github.com/jaywcjlove/awesome-mac#developer-tools) / [IDEs](https://github.com/jaywcjlove/awesome-mac#ides) · ⭐ 85k**

Orca is a workspace for running AI coding agents in parallel. You can give one task to Claude Code, Codex, and others at the same time, each in its own copy of your project, then compare the results and keep the best one. It also includes terminals, a code editor, and a phone app to check on your agents.

![Orca running several coding agents side by side](/blog/apps/orca.webp)

### 7. Hoppscotch

**[Developer Tools](https://github.com/jaywcjlove/awesome-mac#developer-tools) / [API Development and Analysis](https://github.com/jaywcjlove/awesome-mac#api-development-and-analysis) · ⭐ 81k · Free + paid plans**

Hoppscotch is a lightweight, open-source alternative to Postman for testing APIs. Send requests, look at the responses, and save collections to reuse later. It runs in the browser or as a desktop app, and you can self-host it for your team.

### 8. AppFlowy

**[Reading and Writing Tools](https://github.com/jaywcjlove/awesome-mac#reading-and-writing-tools) / [Note-taking](https://github.com/jaywcjlove/awesome-mac#note-taking) · ⭐ 77k · Free + paid plans**

AppFlowy is an open-source alternative to Notion. Docs, wikis, task boards, and databases live in one workspace, with AI built in. Your data can stay on your Mac, and paid plans add cloud sync and collaboration.

### 9. OBS Studio

**[Design and Product](https://github.com/jaywcjlove/awesome-mac#design-and-product) / [Screen Recording](https://github.com/jaywcjlove/awesome-mac#screen-recording) · ⭐ 77k**

OBS is the free standard for screen recording and live streaming. You build "scenes" from sources like your screen, a window, your webcam, and your mic, then record or stream to YouTube or Twitch. It takes a few minutes to learn, but nothing free comes close for tutorials, demos, or streaming.

### 10. Tabby

**[Terminal Apps](https://github.com/jaywcjlove/awesome-mac#terminal-apps) · ⭐ 75k**

Tabby is a modern, highly customizable terminal. It has tabs, split panes, themes, and a built-in SSH and serial client that remembers your connections. It runs on Mac, Windows, and Linux, so your terminal feels the same everywhere.

![The Tabby terminal](/blog/apps/tabby.webp)

**[Reading and Writing Tools](https://github.com/jaywcjlove/awesome-mac#reading-and-writing-tools) / [Note-taking](https://github.com/jaywcjlove/awesome-mac#note-taking) · ⭐ 73k · Free + paid plans**

AFFiNE combines docs, whiteboards, and databases in one app, as an open-source alternative to Notion and Miro. You can switch a page between a document and an infinite canvas to sketch ideas. It works offline and keeps your data local, with paid plans for cloud sync.

### 12. Alacritty

**[Terminal Apps](https://github.com/jaywcjlove/awesome-mac#terminal-apps) · ⭐ 66k**

Alacritty is a terminal built for one thing: speed. It uses your GPU to draw text, has no tabs or extra features, and is configured with a simple text file. People often pair it with tmux or Zellij for tabs and splits.

![The Alacritty terminal showing code](/blog/apps/alacritty.webp)

### 13. Warp

**[Terminal Apps](https://github.com/jaywcjlove/awesome-mac#terminal-apps) · ⭐ 65k · Free + paid plans**

Warp started as a modern terminal and is now an "agentic development environment." Commands and their output are grouped into blocks you can copy or share, and you can use its built-in AI agent or bring your own, like Claude Code or Codex. It recently became open source. It is free to use, with paid plans for more AI.

draw.io is a free diagram app for flowcharts, org charts, network diagrams, and more. The desktop app works fully offline and saves files on your Mac. It is a great free alternative to Visio or Lucidchart.

**[Reading and Writing Tools](https://github.com/jaywcjlove/awesome-mac#reading-and-writing-tools) / [Note-taking](https://github.com/jaywcjlove/awesome-mac#note-taking) · ⭐ 57k · Free + paid plans**

Joplin is an open-source notes app, and a good fit if you are leaving OneNote or Evernote. Motrix is a download manager for big files. It speeds up downloads by splitting them into parts, and it handles HTTP, FTP, torrents, and magnet links in one simple window. Its last release was in 2023, but it still works well.

## Closed-source favorites in this list

Here are the top ten closed-source apps installed most often in the past year, according to Homebrew's public install numbers.

- **[Google Chrome](https://www.google.com/chrome/)** · Free · 436k Homebrew installs: Google's browser, with sync across your devices and the biggest extension library.
- **[Claude](https://claude.ai/download)** · Free + paid plans · 213k Homebrew installs: Anthropic's AI assistant as a desktop app, for writing, research, and coding.
- **[Obsidian](https://obsidian.md)** · Free + paid add-ons · 192k Homebrew installs: a notes app that keeps everything as Markdown files on your Mac, with links between notes and thousands of plugins. Sync and publishing are paid add-ons.
- **[OrbStack](https://orbstack.dev)** · Free for personal use · 183k Homebrew installs: a fast, light way to run Docker containers and Linux machines. A paid license is needed for commercial use.
- **[Tailscale](https://tailscale.com)** · Free + paid plans · 148k Homebrew installs: a private network that connects your devices securely, wherever they are.
- **[Postman](https://www.postman.com)** · Free + paid plans · 140k Homebrew installs: the most widely used app for building and testing APIs.
- **[Cursor](https://cursor.com)** · Free + paid plans · 119k Homebrew installs: an AI code editor built on VS Code, with autocomplete, chat, and a coding agent.
- **[Raycast](https://www.raycast.com)** · Free + paid plans · 116k Homebrew installs: a launcher that replaces Spotlight, with clipboard history, window management, snippets, and AI. I wrote [a whole post about it](/blog/raycast).
- **[Discord](https://discord.com)** · Free + paid plans · 94k Homebrew installs: voice, video, and text chat for communities and friends.
- **[Slack](https://slack.com)** · Free + paid plans · 83k Homebrew installs: team chat, used by most workplaces.

- [awesome-swift-macos-apps](https://github.com/jaywcjlove/awesome-swift-macos-apps) (⭐ 2k): open-source Mac apps written in Swift, from the same maintainer as awesome-mac.
- [awesome-native-macosx-apps](https://github.com/open-saas-directory/awesome-native-macosx-apps) (⭐ 2k): native Mac apps only, nothing built on Electron. I combined it with four other lists to find [the 25 most-starred native Mac apps](/blog/best-native-mac-apps).
